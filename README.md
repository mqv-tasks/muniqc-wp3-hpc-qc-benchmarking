# Pre-optimized VQE circuits for H₂ and LiH (neutral-atom hardware format)

This repository provides **ready-to-run quantum circuits** that prepare the ground states of H₂ and LiH, compiled to the neutral-atom hardware format: parallel CZ layers, and single-qubit gates as [local Z, global √X, local Z, global √X, local Z].

The variational optimization (VQE, Variational Quantum Eigensolver) has **already been carried out on a classical simulator**. The circuits contain fixed, converged parameters. Experimentalists only need to run the circuits on the device, collect measurement counts, and combine them into a molecular energy, following the [Experimentalist Guide](docs/EXPERIMENTALIST_GUIDE.md). **No optimization loop runs on the quantum hardware.**

## Who is this for?

- **Experimentalists:** go to `outputs/<ansatz>/<molecule>/` and the [Experimentalist Guide](docs/EXPERIMENTALIST_GUIDE.md). You don't need to install or run any code. If you only run one set, use `outputs/pair/`: it has by far the shallowest circuits.
- **Developers / reviewers:** the Python pipeline in `src/vqe_native/` shows how the circuits were generated and lets you regenerate them.

## Three ansätze, same energies

The same molecules are delivered with three different ansätze (circuit families). All three reach the exact ground-state energy. They differ in how deep the circuits are on hardware.

| Ansatz | What it is | Works for | Output folder |
|---|---|---|---|
| `uccsd-qiskit` | UCCSD from qiskit-nature on Hartree-Fock. **The original method**, the same one used for the first delivery. | any molecule | `outputs/uccsd-qiskit/` |
| `uccsd-pennylane` | The same UCCSD excitations (same list, same order, same number of parameters), each built with PennyLane's compact `SingleExcitation` / `DoubleExcitation` gates. | any molecule | `outputs/uccsd-pennylane/` |
| `pair` | Compact pair ansatz: spread one electron over the orbitals, copy it to the other spin with one parallel CZ layer, rotate the orbitals. Exact for two active electrons. | 2 active electrons only (H₂, frozen-core LiH) | `outputs/pair/` |

Cost of the measurement circuits on hardware (worst case over each molecule's measurement circuits), generated by `uv run python scripts/summarize_outputs.py`:

| Molecule | Ansatz | Measurement circuits | CZ gates (max) | CZ layers (max) | Global √X pulses (max) | VQE energy (Ha) |
|---|---|---|---|---|---|---|
| H₂ | `uccsd-qiskit` | 5 | 42 | 42 | 82 | −1.13730604 |
| H₂ | `uccsd-pennylane` | 5 | 13 | 11 | 22 | −1.13730604 |
| H₂ | `pair` | 5 | 3 | 2 | 6 | −1.13730604 |
| LiH | `uccsd-qiskit` | 58 | 530 | 507 | 992 | −7.88217588 |
| LiH | `uccsd-pennylane` | 58 | 196 | 153 | 270 | −7.88217599 |
| LiH | `pair` | 58 | 24 | 12 | 26 | −7.88217599 |

Exact energies: H₂ −1.13730604 Ha (PySCF FCI), LiH −7.88217599 Ha (PySCF CASCI over the frozen-core active space). `uccsd-qiskit` uses the optimizer settings of the first delivery (SLSQP default tolerance), which stop 1.1e-7 Ha above the exact LiH energy. The other two use a tighter tolerance.

Why the depths differ:

- `uccsd-qiskit` builds each excitation by exponentiating every Pauli string of the operator with its own CNOT ladder. That works for any operator, but one double excitation alone becomes 8 Pauli strings (about 42 CZ for H₂).
- `uccsd-pennylane` uses PennyLane's hand-derived decompositions of the same excitations (2 CNOTs per single, 14 per double). It is still a full UCCSD circuit that works for any molecule. Caveat: PennyLane's gates leave out the Jordan-Wigner parity (Z) strings, so this is a valid UCCSD-type ansatz with the same parameters, but not the identical operator.
- `pair` only has to prepare one state from |0…0⟩, not implement each excitation operator for every possible input. That is why it is so much shorter, and also why it is exact only for two active electrons. (LiH qualifies because its Li 1s core is frozen: only 2 of its 4 electrons are active.)

## What is in each output folder

`outputs/<ansatz>/<molecule>/` contains:

- `ansatz.qasm`: the converged state-preparation circuit, without measurements.
- `measure_group_N.qasm`: the state preparation followed by a basis-rotation layer and a measurement of all qubits. These are the files to execute, one per group (H₂: 5 groups, LiH: 58).
- `reference.md`: which Pauli terms and coefficients each measurement file covers, the energy offset, the formula to combine the measured expectation values into the total energy, the reference energies to compare against, and the hardware cost of every circuit.

`outputs/v1_sent_to_experiment/` holds the circuits of the **first delivery, exactly as sent** (frozen, checked by checksum). They use the old per-qubit `sx` gate format, not the hardware format. The `uccsd-qiskit` pipeline reproduces their state, and a test checks this.

All generated circuits are OpenQASM 3 and use only three operations:

- `cz`: entangling gate. CZs on disjoint pairs are grouped into one **CZ layer** and run in parallel.
- `gsx`: one **global** √X pulse acting on all qubits at once (defined at the top of each file as `sx` on every qubit).
- `rz`: local virtual Z rotation, with a different phase per qubit.

Barriers separate the circuit into *moments*. Each moment is either a CZ layer or a single-qubit block `rz… gsx rz… gsx rz…` (local Z₁, global √X, local Z₂, global √X, local Z₃). The `ansatz.qasm` files can also end with a layer of only `rz`. `tests/test_hardware_format.py` checks every committed file against these rules.

## How the circuits were generated

- **H₂**, STO-3G, 0.735 Å, no active-space reduction needed: **4 qubits**.
- **LiH**, STO-3G, 1.5949 Å, Li 1s core frozen (`FreezeCoreTransformer`): 2 active electrons in 5 orbitals, **10 qubits** (instead of 4 electrons and 12 qubits). Freezing the core is an approximation, also used in the first delivery: it shifts the energy by 2.3e-4 Ha (0.14 kcal/mol, below chemical accuracy) relative to full LiH/STO-3G FCI (−7.88240341 Ha). "Exact" for LiH therefore means exact within this frozen-core problem.
- Jordan-Wigner mapping. VQE run classically (exact statevector estimator, no shot or hardware noise, SLSQP optimizer) from Hartree-Fock until convergence. `uccsd-qiskit` uses exactly the settings of the first delivery. The other two use a tighter convergence tolerance. For `pair`, parameters that converge to ~0 (symmetry-forbidden or redundant rotations) are removed and VQE is re-run on the smaller circuit.
- Every energy is cross-checked against two independent classical references: exact diagonalization of the same qubit Hamiltonian (`NumPyMinimumEigensolver`), and a direct PySCF calculation built independently of qiskit-nature (FCI for H₂, CASCI over the matching frozen-core active space for LiH). They agree to 1e-6 Ha or better.
- The converged circuit is compiled to the hardware format (`src/vqe_native/native_gates.py`), assuming all-to-all connectivity (reconfigurable neutral-atom array). CZs are packed into as few parallel layers as possible, Z-only gates are moved through CZs (they commute), and the number of single-qubit blocks, each costing 2 global pulses, is kept to the minimum for that CZ layering.
- Hamiltonian terms are grouped into qubit-wise commuting sets, so each group needs only a local basis-rotation layer before measurement. That layer is merged into the last single-qubit block, so it adds no CZs and no extra pulses.

## Repository layout

- `outputs/`: the deliverable circuits and reference data, one folder per ansatz (see above), plus the frozen first delivery.
- `docs/EXPERIMENTALIST_GUIDE.md`: instructions for the experimental team: what each file is and how to run the measurement circuits.
- `src/vqe_native/`: the generation pipeline (molecule → qubit Hamiltonian → ansatz → VQE → hardware-format compilation → measurement grouping → QASM 3 export). The three ansätze are defined in `ansatz.py`; PennyLane's gates are translated into Qiskit in `pennylane_gates.py`.
- `scripts/run_h2.py`, `scripts/run_lih.py`: run the full pipeline for each molecule. `scripts/summarize_outputs.py` prints the comparison table above from the committed files.
- `tests/`: pytest suite, run for every molecule and ansatz. The default run (about 30 s) skips the slow LiH UCCSD cases; `--full` runs everything. It checks qubit counts, VQE against both classical references, the hardware format (pipeline circuits, committed QASM files, random circuits), that the measurement circuits reconstruct the energy, that PennyLane's gates are translated exactly, and that the first delivery is unchanged and still reproduced.

## Regenerating the circuits (optional)

The circuits in `outputs/` are already generated; you only need this to reproduce or modify them. Everything runs in one environment managed by [uv](https://docs.astral.sh/uv/). PennyLane is an optional extra, needed only for the `uccsd-pennylane` ansatz.

```bash
uv sync --extra pennylane                                   # Qiskit + PennyLane (all three ansätze)
uv run pytest                                               # fast checks, about 30 s
uv run pytest --full                                        # everything, about 25 min (adds LiH with both UCCSD ansätze)
uv run python scripts/run_h2.py                             # all three ansätze
uv run python scripts/run_lih.py --ansatz pair              # or just one
uv run python scripts/summarize_outputs.py                  # comparison table
```

Without PennyLane (`uv sync`), the `uccsd-qiskit` and `pair` ansätze work, and the `uccsd-pennylane` tests are skipped.

Generation is deterministic: after regenerating, `git status outputs/` should show no changes.
