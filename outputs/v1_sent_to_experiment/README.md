# v1: circuits sent to the experiment (frozen)

These are the circuits of the first delivery to the experimental team, exactly as sent (commit `8238332` on `main`). They are kept here unchanged for reproducibility and comparison. They are **not** regenerated by the scripts.

- Ansatz: UCCSD (qiskit-nature) on Hartree-Fock, the method that the `uccsd-qiskit` ansatz reproduces today.
- Gate format: `rz`, `sx`, `cz` with per-qubit `sx`. This is **not** the hardware format (parallel CZ layers, global √X) requested afterwards. For that format, see `outputs/<ansatz>/`.
- Cost: H₂ 42 CZ per circuit, LiH 530 CZ per circuit.
- The link to the usage guide inside each `reference.md` is relative to the old location (`outputs/<molecule>/`); the guide is at `docs/EXPERIMENTALIST_GUIDE.md`.

`SHA256SUMS` lists a checksum for every file, and the test suite checks them, so any accidental change is caught. To check by hand:

```bash
cd outputs/v1_sent_to_experiment && shasum -a 256 -c SHA256SUMS
```
